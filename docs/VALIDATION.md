## 行为修正

| 范围 | 修正及回归边界 |
| --- | --- |
| HTTP / 会话 | 认证请求固定 API 来源，拒绝外部目标和 baseURL 覆盖；会话变化后拒绝旧成功/错误；当前 401 才清理会话；显式公开请求不自动读 token |
| 上传授权与资源 | 第三方/未知传输目标不自动携带应用 Bearer；默认回填/预览/下载过滤危险协议；file/all 恢复不限制 MIME 的约定 |
| 图片压缩 | GIF/SVG 保留原文件；实际编码 MIME 决定文件类型和扩展名；画布不可用、绘制失败、非法设置明确拒绝，上传组件可回退原图 |
| 业务中立 | 排序不按某一业务字段固定“合计”位置；路由标题不读取特定业务查询；业务成功校验必须由接入方显式提供 |
| 全屏与存储 | 全屏同步异常/异步拒绝可反馈；默认存储 getter 被浏览器限制时可恢复，不阻断标签初始化 |
| 极短窗口 | 修正分页下边距被样式优先级覆盖；短窗口缩小留白，窄且短时折叠统计文本，正文和分页仍可达 |
| 基础错误边界 | 数字转换抛错使用调用方兜底；错误展示只选有效文本；受限偏好 Cookie 不阻断布局；模型/渲染日志仅投影公开类型与代码 |
| 搜索与分页 | 输入法、控件自有 Enter 和已处理事件不触发搜索；表单重名字段不能覆盖表格分页；隐藏菜单及三级相对路径处理正确，全局搜索键盘动作隔离组合输入 |
| 标签刷新与缓存 | 注册隐藏且禁止缓存的中转路由，限制站内返回目标；刷新释放旧实例且不生成中转标签；空缓存目录仅允许当前可缓存页短暂占位 |
| 图标与导航 | 只渲染真实风格图标导出；选择、清空、Escape 支持键盘与焦点恢复；折叠 Logo 使用完整紧凑标识，外链隔离 opener |
| 浮层适配与动效 | 保留原生 CSS min/max，消除 Antd 双重 padding；短视口浮层自动平移；定位后防滚动聚焦；系统 reduce 偏好抑制局部 Dock 与图标缩放 |
| 错误消费者 | 表格、搜索、确认浮层及上传解析/移除只使用有效文本，异常 message 对象不能成为 React 子节点 |
| 静态规则 | 未显式导入的 logger 与绕过统一入口的 console 写入会被 ESLint 拒绝；保留 logger 模块自己的平台适配例外 |

| 1440 × 900 | 400px | 863px | 正文内部滚动 |
